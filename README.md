# vivo 短剧素材库查询工具

一个功能完整的 vivo 短剧素材库查询和下载桌面工具。

## ✨ 功能特性

- 🔍 **短剧信息查询** - 通过短剧ID快速查询详细信息
- 📱 **响应式设计** - 完美适配桌面端
- 🎬 **视频下载** - 支持单个和批量下载视频
- 📦 **批量打包** - 自动打包多个视频为ZIP文件
- 🔒 **安全防护** - 密码保护访问
- 🎨 **精美界面** - 苹果风格的现代化UI设计

## 🚀 快速开始

### 方式一：直接使用打包版本

1. 下载 `vivo短剧素材库工具.exe`
2. 双击运行即可
3. 输入访问密码：`vivo2026`

### 方式二：从源码运行

1. **安装依赖**
   ```bash
   npm install
   ```

2. **启动应用**
   ```bash
   npm run electron
   ```

### 方式三：打包成桌面应用

```bash
npm run build:win
```

打包完成后，在 `dist` 目录下找到 `vivo短剧素材库工具.exe`

## 📖 使用说明

1. 输入访问密码进入系统
2. 在搜索框中输入短剧ID（如：FUNSHION9538019）
3. 选择是否优先H265格式
4. 点击"查询短剧"按钮
5. 查看短剧信息和剧集列表
6. 可以单独下载视频或批量下载
